Seahorse Script

An esoteric language that uses only the seahorse emoji and whitespace.

Language reference

Program is sequences of the chosen emoji. Groups separated by whitespace become numbers (length of each group).

Instructions are numbers (opcodes). Some take an argument (the next number).

  • 1: push [n]
  • 2: add
  • 3: sub
  • 4: mul
  • 5: div
  • 6: print
  • 7: dup
  • 8: swap
  • 9: pop
  • 10: read (prompt number)
  • 11: jz [offset] (relative, can be negative)
  • 12: halt
